# US clinician-annotated confirmatory set: plan

Status: plan only. No US notes have been annotated. This set is the **confirmatory** test set in
`docs/EVAL_PROTOCOL_LEO.md` (§ test sets). Nothing about LEO generalising to US notes may be
claimed in a manuscript until it exists.

## 1. Why it is needed

- The only native clinician gold is the F-S set: 200 synthetic UK clinic letters, one clinical
  style (real letters were used only in the original ExECT v1 validation, which we do not have). Every headline number (EpExtra silver F1 0.806, LEO vs F-S gold) is UK.
- The target deployment is US notes (Epic-style progress notes, EEG/MRI reports). Style,
  abbreviations (e.g. "LEV", "Keppra XR"), templates and dosing conventions differ
  (`docs/US_NOTE_PREPROCESSING.md`).
- The synthetic sets (synth-v1 eval-100, v2/v3) are generated by an LLM and cannot show real-world
  robustness; they stay secondary.

## 2. Scope of what is annotated

Same seven fields scored against F-S gold, so results are comparable, plus the structured
fields EpExtra already emits:

| field | value type |
|---|---|
| `current_asms` | multiset of generic drug names (with dose where stated) |
| `seizure_frequency` | period, count_min, count_max |
| `epilepsy_type` | enum |
| `predominant_seizure_type` | enum |
| `age_at_onset` | integer years |
| EEG finding, MRI finding | enum (report documents only; second phase) |

Every annotated value carries a **verbatim evidence span** (character offsets), because the
Verify stage requires one. Annotators mark "not documented" explicitly; absence is a label, not
a blank.

Enum vocabulary: the schema in force at annotation time (`docs/SCHEMA_V0_2.md`). Whether to move
to the ILAE 2025 enums is decided in `docs/SCOPE_DECISIONS.md` **before** annotation starts, so
the annotators are not asked to re-label.

## 3. Sampling

- Target **60 notes** (minimum 40, stretch 100). Reasons: the primary set has 40 letters; a
  paired document bootstrap with 60 documents gives roughly ±0.10 half-width on a field-level
  accuracy near 0.7, which is enough to detect large arm differences (≥ 0.10) and not small
  ones. State this limit in the paper.
- Stratify by: note type (clinic progress note, EEG report, MRI report), author/clinic,
  and year. Over-sample documents that mention several ASMs or a change of medication; these are
  the hard cases and are rare in a random draw.
- Draw a fixed random seed list and record it. No note is chosen because a model got it right
  or wrong. The draw is made before any LEO arm sees the notes.
- Notes chosen must be disjoint from any note used to build lexicons, prompts, few-shot
  examples or training data.

## 4. Annotators and procedure

1. Two independent annotators, at least one epileptologist or epilepsy-trained clinician; the second
   may be a trained clinical research coordinator or resident.
2. A pilot of 10 notes, annotated by both, used only to fix the guideline (not scored, not
   reused in the final set).
3. Guidelines: start from the F-S / ExECT conventions
   (`docs/EXECT_V2_ANNOTATION_GUIDELINES_NOTES.md`, `docs/FONFERKO_GOLD_SCOPE.md`) and add US
   rules (e.g. PRN vs scheduled, "weaned off" vs "stopped", formulation names).
4. Independent annotation of the 60 notes; compute agreement (below) **before** adjudication.
5. Adjudication by a third senior clinician, or by consensus meeting, recorded per disagreement.
6. The adjudicated labels are frozen with a hash, in the same way as the F-S gold.

Annotation tool: a small local tool or spreadsheet; no PHI to leave the institution. Do not
use a cloud LLM to pre-annotate (it would leak model bias into the gold).

## 5. Agreement metrics (reported in the paper)

| field type | metric |
|---|---|
| enum fields | Cohen's κ, plus raw agreement |
| multiset (ASMs) | micro-F1 between annotators |
| numeric (frequency, age) | exact agreement within the scorer tolerance (1.0) |
| evidence spans | token-overlap F1 |

Pre-registered expectation: if κ < 0.6 on a field, treat that field as unreliable and report
it separately instead of pooling.

## 6. Governance (to confirm before any note leaves the source system)

These are open items, not assumptions:

- IRB determination or approval for secondary use of notes for NLP; whether exempt.
- De-identification method and who certifies it; whether annotators work inside the secure
  environment. Real notes never go to the SLURM cluster unless that environment is approved for PHI.
- Licensing of the output: the annotations may not be redistributable. If so, publish the
  protocol, agreement statistics and aggregate scores only, as with the licensed ontologies.
- Data-use terms if the notes come from a collaborator rather than our institution
  (`docs/CORPUS_OUTREACH.md` tracks external corpora).
- Local model only: Med42-8B and EpExtra run locally. No note is sent to an external API.

## 7. Deliverables and timeline (relative, no dates assumed)

| step | output |
|---|---|
| T0 | governance sign-off, annotator recruitment |
| T0 + 2 wk | sampling list frozen, guideline v1 |
| T0 + 4 wk | pilot (10 notes), guideline v2 |
| T0 + 8 wk | 60 notes double-annotated, agreement computed |
| T0 + 10 wk | adjudicated gold frozen |
| T0 + 11 wk | all arms in the protocol run once on the set; paired bootstrap |

## 8. What this set decides

- Whether the LEO > specialist-only and LEO > LLM-only results observed on UK letters hold on
  US notes (claims C1 to C5 in the protocol).
- Whether retrieval gaps found on UK letters (`docs/CONCEPT_GOLD_SET.md`) recur on US wording.
  If the same annotators also assign ontology codes for the mentions, it doubles as a second
  mention→concept gold set; budget extra time for this only if the scope decision requires it.
