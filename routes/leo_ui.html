Research use acknowledgment

LEO extracts epilepsy phenotypes from notes for research only. It does not diagnose or recommend treatment.

  • Every value must be checked against its quote.
  • Use on real patient text needs IRB approval and institutionally approved compute.
  • The language model is not loaded here, so there is no second reader and nothing auto-accepts.
Research use only. LEO fills a phenotype table from each note and shows, for every value, the quote it came from, which reader found it (model, rules, or both), and whether it needs a person to look. When the readers disagree, both values are shown. Tested on synthetic notes only: check each value against its quote.
Language model not loaded: rules only, no second reader. Nothing auto-accepts and the 10% accepted audit is empty.
A pasted note can’t be reviewed in the Validator; upload a file for that. Downloads have the same columns either way.

    How this works
      
    Check each value against its highlighted quote, then Accept, Correct, or Deny it, or add a value LEO missed. Deny and Correct need a reason; if the readers disagree, say which was right. Decisions save as you click. They don’t change future extractions, and nothing is trained on them.
    
      
    Keys: ↓/↑ or J/K move · A accept · C correct · D deny · U undo · N/P next / previous note · Esc close form.

    What this keeps
    
    Off by default. When checked, this job’s decisions, quotes, and comments, including note text, are copied to data/leo_training/, which is not deleted after 24 hours. Nothing is trained automatically. Uncheck to delete the copy.
    
  
    
  
    
  
    Score labels (leo learn)
  
    Counts, per field, which reader was right when the two disagreed. Does not change extraction. Turning scores into a reader policy is command-line only (leo learn --emit-policy, after ≥100 scored disagreements per field).
