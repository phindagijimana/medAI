# Open-benchmark preliminary results

These files hold the numbers for the manuscript's preliminary Tables 3–4.

- `open_benchmark_summary.json` — per-arm ArmSummary (schema validity, evidence, per-module metrics)
- `open_benchmark_perfield.csv` — one row per (arm, module, field) with n_applicable, tp/fp/fn/tn, precision, recall, f1

Generated by `scripts/run_open_benchmark.py` against silver labels at `data/fonferko_shadrach_2024/silver_labels_v0_2_1`.

Silver-metric numbers only — treat with the honesty the paper's Limitations section requires.
